### combobulating: the cheapest hosting for Claude Code and other AI agents

An always-on Linux machine with Claude Code installed and kept up to date, a terminal in the
browser, and a mailbox and Telegram for your agent, so it keeps working when your laptop is
closed. 2.99 EUR a month; Claude itself stays on your own Anthropic account.
